# PaddleMarks

Simple GitHub Pages landing page for the PaddleMarks pickleball progress tracking journal.

## Purpose

This site is the stable QR-code hub for the project:

- Printed journal QR -> this landing page
- Printable scoresheet QR -> this landing page
- Landing page -> free printable scoresheet PDF
- Landing page -> current Amazon/KDP listing URL

Keeping QR codes pointed at this page makes the Amazon URL and download links editable later.

## Files

- `index.html` — plain HTML/CSS landing page
- `downloads/pickleball-scoresheet.pdf` — placeholder path for the future printable scoresheet
